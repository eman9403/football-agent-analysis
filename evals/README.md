# Evaluations

This folder will hold versioned scouting questions, expected structured filters, and checks that reports stay faithful to retrieved metrics. Keep a small fixed set that covers normal requests, ambiguous wording, unsupported fields, and empty results. Generated runs belong in `results/`, which is ignored by Git.

Sprint 3 records filter validity, candidate agreement with deterministic search, factual errors, latency, and the Ollama model/prompt versions. Add LangGraph evaluation only if that workflow is adopted.

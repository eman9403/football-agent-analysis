# Sprint 0 Implementation Plan

> **For agentic workers:** Use `superpowers:executing-plans` to implement this plan task by task.

**Goal:** Start a local React page, FastAPI service, and PostgreSQL database, and show their connection status in the browser.

**Architecture:** Vite serves the React page and proxies `/api` to FastAPI. The API checks PostgreSQL with `SELECT 1` and returns a short status response. A shell script installs missing local dependencies, then starts both development servers.

**Tech stack:** React, TypeScript, Vite, FastAPI, psycopg, PostgreSQL, Bash.

**Spec:** `docs/sprint-plan.md`, Sprint 0.

## Global constraints

- Run locally on an Apple M1 Pro with 16 GB memory.
- Require no paid model API or downloaded football dataset.
- Keep data, secrets, local environments, and generated files out of Git.
- Show API failure and database failure as distinct browser states.

## Review focus

- Database stopped: API reports unavailable and the page names the database issue.
- API stopped: the page reports the API issue without a blank screen.
- First load: the page shows a checking state until the request settles.
- Small screens: status remains readable without horizontal scrolling.
- Fresh checkout: the README lists prerequisites and one start command.
